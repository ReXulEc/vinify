A minimalist, native macOS Spotify controller widget designed for your desktop. Clean UI, synchronized progress bar, and seamless system mode compatibility.

---

## Features

* **Native macOS WidgetKit:** Lightweight and sleek desktop widget.
* **Real-Time Sync:** Track currently playing song, artist, and smooth progress bar instantly.
* **Artwork Integration:** Dynamic high-res album cover fetching from Spotify.
* **System Modes Adaptation:** Flawless compatibility with macOS Sonoma/Sequoia **Clear, Dim, and Tinted** modes using native SwiftUI rendering filters.
* **Smart Refresh:** Intelligent update logic that eliminates CPU spikes and UI flickering.
